## 🚀 Project Overview
Misinformation threatens public trust and safety. Manual verification is often too slow to keep up with the viral nature of fake news. 

**TruthGuard** solves this by providing:
1.  **Immediate Feedback:** A "FastNewsDetector" layer that analyzes text in <100ms.
2.  **Deep Analysis:** An AI-powered "GeminiAssistant" that provides context, key findings, and verify claims.
3.  **Visual Explanations:** User-friendly dashboards that highlight suspicious content and show confidence scores.

---

## ✨ Key Features

### 🕵️‍♂️ Hybrid Detection Engine
* **Level 1: FastNewsDetector** (Rule-based): Instant analysis using regex patterns, linguistic indicators, and sensationalism scoring.
* **Level 2: AI Verification** (LLM-based): Deep semantic analysis using **Google Gemini Pro** to cross-reference claims and detect subtle bias.

### 📊 Interactive Dashboard
* **Real-time Statistics:** Visual charts (Pie/Line) showing analysis history and trends.
* **Confidence Scores:** Color-coded probability scores (0-100%) for every analysis.
* **Source Verification:** Automatic URL scraping and domain credibility checks.

### 🤖 TruthBot Assistant
* A built-in AI chatbot allowing users to ask follow-up questions about specific news articles or verification techniques.

## 🏗 System Architecture
The project follows a **Layered Architecture** for scalability:

1.  **Presentation Layer:** Flask (Jinja2) Templates & JSON APIs.
2.  **Business Logic Layer:** * `FastNewsDetector` for rapid triage.
    * `GeminiAssistant` for deep learning analysis.
3.  **Data Access Layer:** SQLAlchemy ORM for database interactions.
4.  **Storage Layer:** SQLite for structured data and file system for logs.

## ⚙ Installation & Setup

### Prerequisites
* Python 3.8 or higher
* A Google Cloud API Key (for Gemini AI)

### Steps

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/AdityaGupta62005/Infosys-Fake-News-Detection-and-Verification-Tool.git]
    cd Infosys-Fake-News-Detection-and-Verification-Tool
    ```

2.  **Create a Virtual Environment**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Configure Environment Variables**
    Create a `.env` file in the root directory:
    ```env
    SECRET_KEY=your_secret_key_here
    GOOGLE_API_KEY=your_gemini_api_key_here
    DATABASE_URI=sqlite:///truthguard.db
    ```

5.  **Initialize the Database**
    ```bash
    flask shell
    >>> from app import db
    >>> db.create_all()
    >>> exit()
    ```

6.  **Run the Application**
    ```bash
    python app.py
    ```
    Access the app at `http://127.0.0.1:5000`
